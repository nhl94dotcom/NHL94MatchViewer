# NHL '94 Game Mechanics

This document is now in two parts, one for each system, because the Genesis and SNES games differ in too many ways that
matter to describe them together:

- **[Sega Genesis](GENESIS_MECHANICS.md)**: `nhl94.bin` and the league ROMs built on it.
- **[Super Nintendo](SNES_MECHANICS.md)**: `NHL94.smc`, NHL94_Classic and the SDL league ROMs.

For what the mechanics mean when you play, see the player's guides: [Genesis](GENESIS_GUIDE.md) and [SNES](SNES_GUIDE.md).
