# Practice card: two shooting tests

Two quick tests that check, in real play, what the scoring maps found by playing shots in the game itself
([SCORING_MAP](SCORING_MAP.md)). Each takes about 15 minutes. **Run the NHL '94 Helper while you play** so every shot
is recorded; the tally boxes are a backup. Afterwards, tell me the game's name (or date and time).

**For both tests:**

- An exhibition game against the computer, you on one team. Use a forward with good Shot Power (on the Genesis, a weak
  shooter can't wind up fully).
- **Stop, then wait about 2 seconds** before shooting, so the goalie sets himself. A defender will come at you, so don't
  wait much longer; if he's on you, skate off and set up again.
- **Wind up fully**: hold the shoot button to the end of the wind-up.
- The aim is the d-pad direction **held while you wind up and release**. Press it after you start the wind-up, so you
  don't skate off the spot.
- Landmarks (both games): the end-zone faceoff dots are 21 feet out from the goal line and 23 feet to each side of the
  middle; the tops of the faceoff circles are about 33 feet out; the blue line is 60 feet out. A skater is about 5 feet
  wide on screen.

---

## Test 1 (Genesis): the Down slapshot straight at the goalie

**Spot:** in the middle (the net's centre line through your skater), between the tops of the circles and the blue line
(about 30-55 feet out). **Buttons:** C to shoot.

1. Twelve slapshots holding **Down**, at the net you attack in period 1.
2. Twelve slapshots holding **Left** or **Right** (alternate), same spot, same net.
3. The same two dozen at the other net (period 2).

| | Shots | Goals | Saves | Missed the net |
|---|---|---|---|---|
| Top net, Down | | | | |
| Top net, Left / Right | | | | |
| Bottom net, Down | | | | |
| Bottom net, Left / Right | | | | |

**The game itself says:** Down goes in about 1 time in 5 at the top net and 1 in 7 at the bottom (up to nearly half
at the best spots, through the goalie's butterfly); Left / Right only a few percent.

---

## Test 2 (SNES): the lane to your left

**Spot:** **2-5 feet to your own left of the middle** (your skater just left of the net's centre line, about half to
one skater-width), **25-40 feet out** (from a little short of the tops of the circles to a little beyond).
"Your left" is the screen's left when you attack up the screen and its right when you attack down. **Buttons:** A to
shoot.

1. Twelve slapshots from the lane spot, aimed at **that same side**: attacking up, hold **Left**; attacking down, hold
   **Right**.
2. Twelve from the **mirror spot** (2-5 feet to your right), aimed at **your right** (attacking up: Right; down: Left).
3. If there's time, the same at the other end.

| | Shots | Goals | Saves | Off the post | Missed the net |
|---|---|---|---|---|---|
| Lane spot, attacking up | | | | | |
| Mirror spot, attacking up | | | | | |
| Lane spot, attacking down | | | | | |
| Mirror spot, attacking down | | | | | |

**The game itself says:** from the lane about half go in at the top net and 1 in 4 or 5 at the bottom; from the mirror
spot almost none (1-2%). On the SNES the exact rate depends on which frames the game skips, which changes with who is
on the ice, so a real game is the only true test.
